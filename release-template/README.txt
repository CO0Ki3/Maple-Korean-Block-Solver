한글 모아모아 솔버 v2 (메이플스토리 「한글 모아모아」 이벤트 도구)

[준비] Node.js LTS 설치: https://nodejs.org  (한 번만)
[실행]
  Windows: start.bat 더블클릭
  macOS:   start.command 더블클릭 (처음에 "확인되지 않은 개발자" 경고가 나오면 우클릭 → 열기)
  공통:    터미널에서  node serve.js
  → 브라우저가 http://localhost:8787 로 자동으로 열립니다. 창을 닫으면 종료됩니다.

[사용]
  솔버 탭: 게임 화면을 캡처해 페이지에 붙여넣으면(Ctrl+V / ⌘V) 판·손패·능력 아이콘을 읽고 추천 배치를 보여줍니다.
           직접 입력도 됩니다 (칸 칠하기, 능력 아이콘, 손패는 라이브러리 클릭).
  시뮬레이터 탭: 규칙대로 자동으로 게임을 두거나 여러 판을 돌려 점수 분포를 봅니다.
  모든 계산은 내 컴퓨터 안에서만 돌고, 인터넷에 아무것도 보내지 않습니다. (폰트만 Google Fonts에서 받습니다)

[문제가 있을 때]
  - "Node.js 가 필요합니다": Node.js 설치 후 다시 실행.
  - 포트 8787이 쓰이는 중이면 8788~8797 중 빈 포트로 열리고 주소가 터미널에 표시됩니다.
  - 격자를 못 읽으면 솔버 탭의 「판 위치 직접 지정」으로 판의 왼쪽 위·오른쪽 아래를 클릭하세요.
