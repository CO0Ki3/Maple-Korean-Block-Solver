# 한글 모아모아 솔버

메이플스토리 '한글 모아모아' 이벤트(10×16 블럭 퍼즐)용 도우미입니다. 판과 손패 3개를 넣으면 놓는 순서, 위치, 회전·반전을 계산해 줍니다.

## 실행

`block-solver.html`을 크롬이나 엣지로 열면 됩니다. 설치는 필요 없습니다.

## 사용법

1. 게임 화면을 캡처(`Win+Shift+S`)한 뒤 페이지를 한 번 클릭하고 `Ctrl+V`를 누릅니다. 판, 손패, 능력칸을 자동으로 읽고 바로 계산합니다.
2. 직접 입력할 수도 있습니다. 판은 칸을 눌러 칠하고, 손패는 슬롯을 고른 뒤 라이브러리에서 블럭을 누릅니다. 3개가 차면 자동으로 계산합니다.
3. 추천대로 놓은 뒤 '전부 놓았어요 · 판에 반영'을 누르거나, 다음 턴 스크린샷을 붙여넣으면 이어집니다.

## 기능

- 회전·반전을 모두 고려한 배치 탐색
- 블럭 출현 횟수를 기록해 확률로 반영
- 능력칸(⊙ 점찍기 / ⇄ 바꿔뽑기) 인식과 계산 반영
- 바꿔뽑기 기대값 분석
- 처음 보는 블럭 자동 추가, 직접 그려서 추가
- 평가 가중치 조절

판, 기록, 설정은 브라우저(localStorage)에 저장됩니다.

## 주의

- 개인적으로 쓰려고 빠르게 만든 도구라 버그가 있을 수 있습니다.
- 스크린샷 인식은 제 화면 기준으로 맞춰서 해상도나 화면 구성이 다르면 틀릴 수 있습니다. 이럴 때는 '판 위치 직접 지정'을 쓰거나 직접 고쳐주세요.
- 회전 버튼은 시계 방향, 반전은 좌우 뒤집기로 가정했습니다. 다르면 설정에서 바꾸세요.
